# Tokyo Photo Map

An interactive map of Tokyo showcasing personal photography, organised by railway lines and stations.

Built with React, TypeScript and Vite.

## Getting Started

**Install dependencies**
```bash
npm install
```

**Start development server**
```bash
npm run dev
```

**Build for production**
```bash
npm run build
```

**Preview production build**
```bash
npm run preview
```
